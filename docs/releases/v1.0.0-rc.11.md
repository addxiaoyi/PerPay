# StarPAY 1.0.0-rc.11

新增银行卡、支付宝和微信零钱收款账户的加密保存、管理员审核及自动出款队列。
提现先冻结余额；审核通过后才能交给已验收的通道。请求超时或重启后只查询原单，
验签成功且订单与金额一致后才确认结果。自动出款记录禁止重复登记线下打款。

此版本是开发候选，真实出款默认关闭。中国银行银企对接、微信商家转账权限待核实；
支付宝适配器尚未注册到生产。不能将本版本或测试通过视为真实出款已可用。

数据库迁移新增 schema 67；保留原 PERPAY_MASTER_KEY，升级前验证备份恢复。
旧 schema 66 程序不能打开升级后的数据库，回退不能覆盖新产生的财务记录。
历史镜像命名参考为 ghcr.io/mashiro0619/perpay:1.0.0-rc.11，本次未发布此镜像。
[恢复说明](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.11/docs/maintenance.md#固定版本与回滚)。
