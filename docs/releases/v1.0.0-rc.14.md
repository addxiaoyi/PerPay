# StarPAY 1.0.0-rc.14

Adds a selectable fa-piao provider for merchant tax invoices. The provider uses its own enterprise ID, taxpayer and billing account, supports confirmed Alipay and WeChat orders, and keeps issuance disabled until explicitly enabled.

Schema 70 preserves the existing schema 69 migration, records the selected provider on seller profiles, accepts both confirmed payment types and stores immutable provider receipts. Back up before upgrading; restore the pre-upgrade database when rolling back to rc.13 or earlier. Do not run an older binary against schema 70.

This is a source candidate; the expected image tag is `ghcr.io/mashiro0619/perpay:1.0.0-rc.14`, which has not been published by this task. Back up the database and retain its original `PERPAY_MASTER_KEY` before upgrading.

See [fa-piao configuration](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.14/docs/fa-piao-invoices.md) and [maintenance and rollback](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.14/docs/maintenance.md#固定版本与回滚) for private credential files, activation gates and the unresolved-request recovery limitation.
