# StarPAY 1.0.0-rc.21

Hono is updated from 4.13.13 to 4.13.21 and @hono/node-server from 2.1.5 to 2.1.11. The installed versions were in the affected ranges of seven published GitHub advisories. These updates include fixes for wildcard middleware bypass and raw-backslash path normalization at the reverse proxy boundary. Local HTTP regression tests verify that admission middleware still runs for encoded line terminators and that raw-backslash paths are rejected before reaching handlers.

The minimum Node.js version, CI and pinned container base move to the November security release 24.22.3. Production uses a separate verified runtime path so the prior runtime remains available for recovery. The release does not enable Node HTTP/2/TLS serving, merchant payments, or invoice issuance beyond existing configuration.

Schema remains 74. Existing orders, ledger records and private settings are preserved. Maintain a verified backup and `PERPAY_MASTER_KEY`; see [fixed-version rollback](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.21/docs/maintenance.md#固定版本与回滚). The intended container tag `ghcr.io/mashiro0619/perpay:1.0.0-rc.21` is not published.

The server deployment was verified on 2026-11-23: rc.21, schema 74, Node.js 24.22.3, Hono 4.13.21 and @hono/node-server 2.1.11 are active. Public admission and balance API authentication checks pass without creating financial records. Real invoice execution remains disabled. The pre-existing aged pending-order alert and low disk space remain unresolved; shared Nginx and the separate legacy Next.js application were not upgraded. See [security findings and validation](../security-review-20261123.md).

Sources: [Hono wildcard middleware advisory](https://github.com/advisories/GHSA-h7mg-cq63-vhpq), [Node adapter path advisory](https://github.com/advisories/GHSA-jpvv-r467-5p4w), [Node.js 24.22.3 security release](https://nodejs.org/en/blog/release/v24.22.3). npm audit is checked against registry.npmjs.org because the configured mirror does not implement the security audit endpoint.
