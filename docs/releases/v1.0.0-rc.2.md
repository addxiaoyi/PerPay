# PerPay 1.0.0-rc.2

This is an unpublished release candidate for isolated migration and compatibility verification.
It must not replace a stable deployment until the production cutover gates pass.

## Highlights

- Adds isolated EPay snapshot authentication and migration verification.
- Adds exact-money provider identity checks and atomic ledger plus callback outbox handling.
- Adds merchant-bound compatibility checks for orders, notifications, ledger evidence and invoices.
- Adds recovery experiments and protected configuration handling for isolated validation.

## Upgrade and recovery

The candidate uses the current migration catalog and must be upgraded only after a verified database backup and recovery-key check. Keep `PERPAY_MASTER_KEY` and the database backup together during recovery. Follow the fixed-version rollback procedure in the [maintenance guide](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.2/docs/maintenance.md#固定版本与回滚).

The image reference for this candidate is `ghcr.io/mashiro0619/perpay:1.0.0-rc.2`. Publishing this file or building the image does not authorize production deployment or traffic cutover.
