# StarPAY 1.0.0-rc.12

微信收款账户增加一次性 OAuth 绑定、免确认收款授权、授权撤销通知和官方转账适配器。
出款前查询授权，结果未知只查询原单；付款身份、收款身份、应用和金额必须一致。
新增整笔退回入账、日终查单核对、人工账单比较及管理员查询页面。

这是未部署的候选版本。真实出款默认关闭；支付宝当前应用的只读转账查询返回已验签的
`insufficient-isv-permissions`，中行银企对接和微信商家转账权限待确认。
隔离测试通过不代表真实到账，人工导入账单也不作为自动入账证据。

schema 68 增加授权历史、退回与对账表，保留原 PERPAY_MASTER_KEY。
升级前验证备份恢复。schema 66/67 程序不能打开新库；不能用旧快照覆盖新增财务记录。
历史上游镜像命名参考为 ghcr.io/mashiro0619/perpay:1.0.0-rc.12，本次未发布此镜像。
