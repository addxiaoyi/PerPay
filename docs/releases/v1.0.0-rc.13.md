# StarPAY 1.0.0-rc.13

商户后台新增微信服务商数电普通发票接入：逐商户绑定开票主体、授权邀请和开票员选择、真实订单开票申请、异步查询、即时文件下载。订单实收主体必须与开票主体一致；支付宝订单暂不支持。

业务服务器可使用商户 HMAC 签名提交申请、查询状态和取得文件。后台每 30 秒分批同步未完成申请，页面自动显示最新结果；同一请求保持幂等，未知结果只查询，停止接收订单时同步停止新增开票并等待在途请求完成。提供只读上线检查脚本和默认关闭的配置模板。

增加申请幂等、未知结果查单、明确失败最多五次补开、开票与退款互斥、红冲状态核对和新旧开票路径防重复约束。schema 69 保存独立商户配置及不可覆盖的申请快照。服务商开票权限、卡券模板和各商户税务授权必须单独完成，默认不启用真实开票。

这是未发布的候选版本，未验证生产真实开票。预计镜像标签为 `ghcr.io/mashiro0619/perpay:1.0.0-rc.13`，本次未发布该镜像。升级前备份数据库并保留原 `PERPAY_MASTER_KEY`；旧 schema 68 二进制不能直接打开 schema 69 数据库。
