# 商户余额充值

在商户门户侧边栏打开「余额充值」，填写金额并选择支付宝网页支付或微信扫码。创建订单后打开收银台完成付款，返回页面核对「已到账」及可用余额。充值本金全额入账，不扣商户交易手续费，支付通道成本由平台承担。冻结余额不可用于交易。

创建订单、页面跳转、支付截图和浏览器返回都不证明到账。系统只接受原支付通道的验签结果和原订单金额，并在同一事务中确认付款、增加余额和记录凭证。重复请求和回调不会重复充值。充值不向外部商品网站投递支付通知。

充值余额可以用于向其他已接入网站的商户付款，或购买100元/365天开票年服务。充值本金不是商品或平台服务销售收入，不作为自动开票金额；年服务购买不会打开平台真实开票。

接口位于 `/pay/api/merchant/epay/topups`，会话为 `/topups/session`。仅商户所有者和平台管理员可创建充值，必须使用本站登录、同源请求和独立充值 CSRF。POST JSON 包含 `requestId`、元单位字符串 `amount` 和 `channel`（`alipay_web` 或 `wechat_native`）。不要复用已使用的请求号创建不同金额的充值。

遇到超时请使用原请求核对结果并查看最近充值记录，不要直接重复支付。退款需要依据原充值订单及可用余额处理，不能用人工截图直接增加余额。
