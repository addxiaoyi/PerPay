# 支付宝出款权限与隔离联调

2026-11-07 对当前生产收款应用进行了只读转账查单核查。请求仅查询一次随机且未曾
提交的出款单号，没有提交转账、退款或修改数据库。支付宝响应验签通过，HTTP 400，
业务码为 `insufficient-isv-permissions`。

结论：当前应用缺少本次转账查询所需权限，不能启用自动出款。该结果不能单独证明
企业支付宝账户从未签约转账产品，也不能排除产品已签约但应用未获授权；需要同时核对
账户、应用、产品及业务场景。收款接口正常不等于转账权限已开通。

## 后台核对清单

- 支付宝商家平台查看商家转账/单笔转账产品的实际签约状态、主体、准入场景和额度。
- 开放平台查看当前应用是否获准调用 `alipay.fund.trans.uni.transfer` 与
  `alipay.fund.trans.common.query`，是否为本企业自研应用，以及证书模式是否匹配。
- 核对资金用途属于已批准业务场景，收款人类型、收款身份和实名校验要求。
- 若是服务商代签约场景，使用该场景授权的签约查询接口；不要把服务商签约查询
  当成所有普通应用都可使用的通用权限接口。
- 将确认后的产品名称、场景名、额度、应用权限状态提供给联调人员，私钥仍留在服务器。

## 已准备的隔离联调

`npm run test:payouts` 使用临时 RSA 密钥、合成平台签名和拦截传输验证下单、原单
查单、篡改拒绝、资金冻结与退回。不会调用真实出款接口。

权限开通后先在渠道提供的测试能力内验证；若渠道没有可用沙箱，不伪造沙箱地址。
真实验收需明确付款账户、收款人和金额，取得单次授权后再执行小额验证，最终核对
渠道状态、资金流水、系统账本和回单。未确认状态保留冻结款，不换单重打。

官方接口：[单笔转账](https://opendocs.alipay.com/open/03dcrl)、
[转账业务单据查询](https://opendocs.alipay.com/open/029i7a)。
