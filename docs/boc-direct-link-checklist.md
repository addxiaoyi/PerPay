# 中国银行银企对接咨询清单

用途：StarPAY 向已审核的入驻商户结算，收款方可能是企业银行账户或个人银行卡。
公户在中国银行；当前尚未确认银企对接及付款权限。以下是询问清单，不代表银行已同意开通。

## 可直接发给客户经理

你好，我们的对公账户在中国银行，想把公司自有的 StarPAY 系统接入银企对接。
业务是向已审核的入驻商户结算，可能涉及公对公、公对私和跨行转账。希望管理员在
系统里审核后发起付款，并能自动查询结果、下载回单、核对日终账单和处理退回款。

请先帮忙确认这种业务适用什么产品，是否需要平台结算或其他专门协议，不能使用
普通企业付款产品的部分请直接说明。我们会提供真实的交易、合同、资金来源和用途。

请提供办理资料清单、接口文档版本、测试接入方式，以及负责技术联调的联系人。
还想确认：是否支持 Linux 服务器，是否需要前置机、USBKey、专线或 IP 白名单；
付款能否由接口直接执行，还是每笔必须在企业网银二次审批；单笔、日累计限额、
费用、服务时间、跨行到账及退回时效分别是什么。

## 办理前准备

- 公司名称、统一社会信用代码、开户行、公户信息；通过银行指定渠道提供，不放公共仓库。
- 法人及经办人身份证明、单位授权书、银行要求的申请表和预留印鉴。以开户行最新清单为准。
- StarPAY 网站、业务流程、商户入驻与结算协议、真实交易场景、资金来源和用途说明。
- 预计日/月笔数、单笔范围、峰值、收款方类型、跨行比例和希望的审批流程。
- 财务、技术、运维负责人；服务器系统、出口 IP、网络与证书托管方案。

## 必须问清的接口与行为

1. 查询、付款、跨行、公对私是否需要分别签约。谁有制单、授权、付款及查询权限。
2. 幂等单号格式与保留周期；超时后能否按原单查单；“受理”和“已到账”的不同状态。
3. 重复指令、处理中、余额不足、收款行拒绝、撤销、原路退回的明确错误码和处理办法。
4. 付款方和收款方校验字段、户名校验、联行号、附言及用途填写要求。
5. 回调的验签、证书更新、重放防护、重试频率；没有回调时的查询频率限制。
6. 账单生成时间、时区、分页/文件格式、下载校验、付款/手续费/退回款的关联编号。
7. 成功后退回是否有独立退回流水；全额/部分退回、跨日退回如何查询和对账。
8. 测试账户与模拟场景、准入验收、灰度限额、停用接口和应急联系人。

## 交给开发的材料

正式产品名称、合同/权限范围、接口版本、测试地址、报文及签名规范、状态与错误码、
回单和账单样例、幂等/限流/超时规则。证书私钥保存在受控密钥文件，不通过聊天或 Git 传递。

中国银行公开规则说明银企对接属于企业电子银行渠道，支持范围、认证工具和授权
流程应按实际签约核实：[企业网银业务规则](https://www.boc.cn/ebanking/service/cs1/200810/t20081022_989533.html)。
